# Red_panda_detection-
## 🐾 Red Panda Detection (YOLOv8)

This project implements a **Red Panda Object Detection** model using **YOLOv8**, trained on a custom dataset. The goal is to accurately detect red pandas in images using a lightweight and efficient deep learning model.

The repository contains:
- Training notebook (`redpanda.ipynb`)
- Trained model weights (`best.pt`)
- Prediction outputs (`predictions/`)
- Requirements file (`requirements.txt`)

---

## 🚀 Features

- YOLOv8-based object detection  
- Custom dataset training  
- High‑accuracy model (`best.pt`)  
- Easy inference on new images  
- Sample predictions included

## 📦 Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

Or install YOLOv8 directly:

```bash
pip install ultralytics
```

---

## 🏋️ Training (from notebook)

Training was performed inside the Colab notebook:

```python
from ultralytics import YOLO

model = YOLO("yolov8n.pt")
model.train(data="data.yaml", epochs=50, imgsz=640)
```

You can open `redpanda.ipynb` to retrain or modify the pipeline.

---

## 🔍 Inference (Run Detection)

Use the trained model to run predictions:

```python
from ultralytics import YOLO

model = YOLO("best.pt")
results = model.predict("your_image.jpg", save=True)
```

All saved predictions will appear in the `predictions/` folder.
